# Publication figures

- `mortality-by-decade.svg`: stacked average annual fatalities; 2020–25 is separated and hatched as partial/preliminary.
- `mortality-per-million.svg`: descriptive combined mortality per million residents; eight completed decades only.
- `publication-qr.svg`: QR code linking to the live Homework 4 webpage.

The two chart SVGs are regenerated from `../assets/data/` by `../scripts/build_charts.py`. They preserve vector shapes and text for PDF export. The webpage supplies meaningful alt text, complete accessible tables, and source/units/period/caveat captions. There are no invented sample data points.
